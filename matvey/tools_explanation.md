# Подробный разбор модуля `tools.py`
**Назначение файла:** Реализация программных инструментов (Tools / Function Calling) для агентного AI-ассистента путешествий по Приморскому краю (проект Т-Банк × Сириус).

---

## 1. Зачем нужен этот модуль в архитектуре проекта

В обычном чате языковая модель (LLM) берёт информацию только из своей памяти, поэтому она неизбежно **галлюцинирует**:
* Придумывает несуществующие музеи и базы отдыха.
* Не знает реального прогноза погоды на конкретные даты.
* Ошибается в расчёте времени в пути (например, утверждает, что от Владивостока до Тернея можно доехать за 3 часа вместо 10).
* Не знает, открыты ли заправки по дороге.

Модуль `tools.py` превращает модель из «болталки» в **настоящего агента (слайд 8 презентации)**:
1. Модель читает запрос пользователя.
2. Сама решает, какие инструменты вызвать и с какими параметрами.
3. Бэкенд вызывает функции из `tools.py` и получает реальные факты из внешних сервисов.
4. Модель собирает итоговый план, опираясь **только на проверенные данные**.

---

## 2. Разбор функций модуля (Data Layer)

### 2.1. `get_coordinates(place_name: str)`
* **Сервис:** [Nominatim OpenStreetMap](https://www.google.com/search?q=https%3A%2F%2Fnominatim.openstreetmap.org%2F)
* **Что делает:** Принимает текстовое название любого географического объекта в Приморье (город, посёлок, бухта, сопка, мыс) и возвращает точные координаты (`latitude`, `longitude`) и официальное название.
* **Как работает внутри:**
  1. Добавляет к запросу строку `", Приморский край, Россия"`, чтобы отсечь одноимённые города в других регионах.
  2. Отправляет GET-запрос с обязательным заголовком `User-Agent`.
  3. Если поиск с припиской региона не дал результатов (например, для локальных сопок вроде «Пидан»), делает запасной поиск по исходному названию.
* **Зачем агенту:** Без координат невозможно запросить погоду, достопримечательности или построить маршрут.

---

### 2.2. `get_weather_forecast(latitude: float, longitude: float, days: int = 2)`
* **Сервис:** [Open-Meteo API](https://www.google.com/search?q=https%3A%2F%2Fopen-meteo.com%2F) (100% бесплатно, без ключей)
* **Что делает:** Возвращает прогноз погоды для конкретной точки Приморья на 1–7 дней вперёд в часовом поясе `Asia/Vladivostok`.
* **Возвращаемые метрики:**
  * Максимальная и минимальная температура воздуха (`°C`).
  * Суммарное количество осадков за день (`precipitation_sum` в мм).
  * Максимальные порывы ветра (`windspeed_10m_max` в км/ч).
  * Текстовый статус (`conditions_summary`): «Дождь/осадки», «Ветрено» или «Благоприятно».
* **Зачем агенту:** Выполнить требование слайда 5 («Велопрогулка под обещанным ливнем — ошибка; хороший план учитывает прогноз погоды»). Если ожидается дождь более 2 мм или штормовой ветер >30 км/ч, агент обязан скорректировать план или предупредить туриста.

---

### 2.3. `get_nearby_attractions(latitude: float, longitude: float, radius_meters: int = 15000)`
* **Сервис:** [Wikipedia API Geosearch](https://www.google.com/search?q=https%3A%2F%2Fwww.mediawiki.org%2Fwiki%2FAPI%3AGeosearch)
* **Что делает:** Ищет статьи русской Википедии, привязанные к координатам в заданном радиусе (по умолчанию 15 км).
* **Возвращаемые данные:**
  * Список реальных объектов (памятники, маяки, форты Владивостокской крепости, бухты, острова).
  * Точное расстояние в метрах от центра поиска до каждого объекта.
  * Идентификатор статьи в Википедии (`wiki_page_id`).
* **Зачем агенту:** Это главная защита от галлюцинаций. Модель рекомендует туристу только те места, которые физически существуют и имеют историческую/туристическую ценность.

---

### 2.4. `calculate_route(start_lat, start_lon, end_lat, end_lon, mode: str = "driving")`
* **Сервис:** [OSRM Project](https://www.google.com/search?q=http%3A%2F%2Fproject-osrm.org%2F) (Open Source Routing Machine)
* **Что делает:** Рассчитывает реальную дорожную сеть между двумя точками для автомобиля (`driving`) или пешехода (`walking`).
* **Возвращаемые данные:**
  * Реальная дистанция с учётом изгибов дорог в километрах (`distance_km`).
  * Время в пути в минутах и часах (`duration_minutes`, `duration_hours`).
* **Важная техническая деталь:** OSRM в URL принимает координаты в порядке `долгота,широта` (`lon,lat`), в отличие от стандартного `lat,lon`. В коде это учтено: `coordinates = f"{start_lon},{start_lat};{end_lon},{end_lat}"`.
* **Зачем агенту:** Проверка выполнимости плана. Если турист хочет успеть за выходные объехать 4 удалённых района, агент рассчитает чистое время за рулём и покажет, что на осмотр достопримечательностей времени не останется.

---

### 2.5. `get_nearby_gas_stations(latitude: float, longitude: float, radius_meters: int = 15000)`
* **Сервис:** [Overpass API](https://www.google.com/search?q=https%3A%2F%2Foverpass-turbo.eu%2F) (OpenStreetMap)
* **Что делает:** Находит АЗС по тегу `amenity=fuel` в радиусе 15 км от указанной точки маршрута.
* **Возвращаемые данные:** Список заправок с названиями операторов/брендов (ННК, Роснефть и др.) и координатами.
* **Зачем агенту:** Выполнить требование слайда 5 («Знает, где по пути реально заправиться»). Приморский край имеет большие перегоны между населёнными пунктами, где кончившийся бензин критичен.

## 3. Разбор структуры `TOOLS_SCHEMA` (JSON Schema)

`TOOLS_SCHEMA` — это список деклараций функций по стандарту OpenAI / OpenRouter. Когда бэкенд отправляет запрос к модели, он передаёт этот массив в параметре `tools`.

Для каждого инструмента описано:
1. `name` — системное имя функции (например, `"get_weather_forecast"`).
2. `description` — семантическое описание на русском языке. Модель читает это описание и решает, подходит ли инструмент под интент пользователя.
3. `parameters` (JSON Schema):
   * `type: "object"`.
   * `properties` — список входных параметров, их типы (`string`, `number`, `integer`) и пояснения.
   * `required` — список параметров, без которых функцию вызывать нельзя.

Благодаря строгой типизации модель возвращает аргументы в валидном JSON-формате (например, `{"latitude": 43.1155, "longitude": 131.8855, "days": 2}`).

## 4. Разбор диспетчера `TOOL_MAP`

```python
TOOL_MAP = {
    "get_coordinates": get_coordinates,
    "get_weather_forecast": get_weather_forecast,
    "get_nearby_attractions": get_nearby_attractions,
    "calculate_route": calculate_route,
    "get_nearby_gas_stations": get_nearby_gas_stations
}
```

Это паттерн **Dispatch Table (таблица диспетчеризации)**:
* Вместо громоздких конструкций `if fn_name == "get_coordinates": ... elif ...` бэкенд находит функцию по ключу: `func = TOOL_MAP[fn_name]`.
* Функция вызывается динамически: `await func(**fn_args)`.
* Это позволяет легко добавлять новые инструменты (например, поиск отелей или расписание электричек), не меняя логику самого агентного цикла.

## 5. Полная схема жизненного цикла одного запроса

```text
[Пользователь]
      │ "Хочу в Находку на машине на 2 дня"
      ▼
[FastAPI Backend] ── (system_prompt + tools: TOOLS_SCHEMA) ──► [OpenRouter LLM]
                                                                     │
                                    Модель возвращает Tool Call ◄────┘
                                    name: "get_coordinates"
                                    args: {"place_name": "Находка"}
      │
      ▼
[TOOL_MAP["get_coordinates"]] ──► Nominatim OSM ──► (lat: 42.82, lon: 132.87)
      │
      ▼
[FastAPI Backend] ── (результат координат) ──────────────────► [OpenRouter LLM]
                                                                     │
                                    Модель возвращает Tool Calls ◄───┘
                                    1. get_weather_forecast(42.82, 132.87)
                                    2. calculate_route(43.11, 131.88, 42.82, 132.87)
      │
      ▼
[Выполнение API погоды и OSRM] ──► (погода: +16°, OSRM: 180 км, 3.5 часа)
      │
      ▼
[FastAPI Backend] ── (все факты собраны) ────────────────────► [OpenRouter LLM]
                                                                     │
                                  Финальный структурированный JSON ◄─┘
                                  (план на 2 дня с точными фактами)
      │
      ▼
[Фронтенд на React/Vue] ── (карточки дней + линия маршрута на Leaflet карте)
```
