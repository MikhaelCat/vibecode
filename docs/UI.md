# UI: что есть, чего нет и что должно быть

Фронтенд — `src/frontend/` (ванильный JS + Leaflet), собирается в `src/frontend/dist`
и отдаётся тем же axum-сервером. Отдельного Node-сервера и CORS нет.

## Запуск

```bash
npm --prefix src/frontend run build
env MOCK_LLM=1 BIND=127.0.0.1:8080 cargo run --bin travel-ai
# http://127.0.0.1:8080
```

Проверка UI:

```bash
BASE_URL=http://127.0.0.1:8080 bash scripts/frontend_test.sh
```

## Визуальный язык

Тёмный «морской» hero с атмосферным градиентом и сеткой, крупная типографика
Unbounded, светлые секции на тёплой бумаге, бирюзовый акцент и аккуратные
карточки с мягкими тенями.

| Токен | Значение | Где |
|---|---|---|
| Ink | `#071a24` | hero, кнопки, футер, текст |
| Sea | `#0f766e` | акценты, активные элементы, маршрут |
| Mint | `#5eead4` | заголовок hero, номера шагов |
| Paper | `#f7f6f2` | фон секций и полей |
| Cloud | `#ffffff` | панели, карточки, фон результатов |
| Manrope | 400–700 | текст и интерфейс |
| Unbounded | 500–600 | заголовки и крупные цифры |
| Радиусы | 14–28px | панели, карточки, кнопки, карта |
| Тени | мягкие | карточки, панель формы, карта |

Полосы: hero → форма с превью-панелью → карта → план → футер. Заголовок 1–7
дней, форма с счётчиком символов, примеры запросов, живой таймлайн этапов,
карта в скруглённой рамке, вертикальный таймлайн точек и отдельная секция
«Где остановиться».

## Все элементы

| Элемент | Селектор | Сейчас | Должно быть |
|---|---|---|---|
| Логотип `vibecode` | `.brand` | ссылка на `/`, перезагружает SPA | оставить; при клике сбрасывать форму/план |
| Регион | `.region` | статичный текст «Приморский край» | оставить |
| Статус | `#health` | `онлайн` после `/api/health`; без модели и `mock-llm` | `онлайн` / `нет связи`; при ошибке — причина |
| Текстовое поле | `#q` | обязательное, до 1000 символов, счётчик | Enter отправляет форму; лимит API соблюдён |
| Дата «С» | `#start_date` | по умолчанию завтра; native date | блокировать прошлые даты |
| Дата «По» | `#end_date` | по умолчанию +2 дня (3 дня); clamp 1–7 дней | даты из формы главнее текста, если их меняли |
| Транспорт | `#transport` | «Из текста запроса» по умолчанию; `car`, `foot`, `bike`, `transit` | явный выбор главнее текста |
| Кнопка «Собрать маршрут» | `#go` | POST SSE; disabled и «Собираю…» на время | ошибка + «Повторить», без demo-подмены |
| Чипы примеров | `.chip` | заполняют `#q`, не отправляют | оставить |
| «Токен доступа» | `#token-box` / `#token` | скрыт, если `auth_required:false`; значение в localStorage; заголовок `x-app-token` | показывать только при `APP_TOKEN`; кнопка «Выйти» |
| Вкладки дней | `.tab` | «День N» + дата; переключают день | клавиатурная навигация |
| Карточка точки | `.stop` | время, название, `place_id`; клик — flyTo маркера | раскрывать описание/источник |
| Где остановиться | `#lodging-box` / `.lodge` | все `plan.lodging_options`; выбранный вариант и рекомендация | ссылка на бронирование/цену за все ночи |
| Маркеры | Leaflet | нумерованные «капли», fitBounds по точкам дня | кластеризация при >20 точках |
| Линия маршрута | Leaflet | прямая через координаты точек | реальная геометрия OSRM (`legs[].geometry`) |
| Карта | `#map` | OSM tiles, zoom +/−, `invalidateSize` при resize | fallback tiles/offline; кнопка «на весь экран» |
| Атрибуция | Leaflet control | **удалена по запросу** | OSM-кредит остаётся в футере (лицензия) |
| Источник точки | `.stop .source` | ссылка «Источник: Wikipedia/OpenStreetMap» вместо сырого `place_id` | при клике открывается объект в источнике |
| Отказ | `#refusal` | текст отказа, план скрыт, кнопка «Попробовать пример» | оставить |
| Ошибка | `#error` | причина и кнопка «Повторить» | cancel/timeout |
| Футер | `.foot` | OSM, Open-Meteo, OSRM | оставить; ссылки на лицензии |

## Отели

Если инструмент `find_lodging` вернул варианты, бэкенд отдаёт **все** варианты в
`plan.lodging_options`, а выбранный — ещё и в `plan.lodging` / `days[].lodging_id`.
UI показывает список «Где остановиться»: номер, название, населённый пункт, тип,
цену за ночь, метки «рекомендация» и «в плане». Если вариантов нет — секция
скрывается. Бронирования и внешних ссылок пока нет.

## Состояния

- **Пусто** — форма и карта Приморья; результатов нет.
- **Загрузка** — stages: «Проверяю тему → Разбираю запрос → Собираю план → Проверяю план → Готово».
- **План** — title, summary, meta (даты, транспорт, км, стоимость, погода, ночёвка, предупреждения), tabs, stops, lodging.
- **Отказ** — блок `#refusal`, без плана; HTTP при этом 200.
- **Ошибка** — красный блок с причиной и кнопкой «Повторить»; демо-подмены нет.
- **Даты** — если поля не трогали, даты берутся из текста запроса и подставляются в форму после разбора. Если выбрали вручную — форма главнее текста.
- **Токен** — поле скрыто, пока `/api/health` не вернёт `auth_required:true`.

## Что удалено по запросу

- Бейджи `мок` у точек и ночёвки.
- Бейдж `mock-llm` в шапке; вместо него `онлайн`.
- Контрол атрибуции Leaflet «Leaflet | © участники OpenStreetMap».
- OSM-кредит при этом остался в футере — этого требует лицензия ODbL.
- Поле «Токен доступа» скрыто, если токен на сервере не задан.
- Панели «Проверка плана» и «Как собран план» убраны из UI; validation и trace доступны только в API.

## Что должно быть в API для UI

`POST /api/plan` и `/api/plan/sync` принимают:

```json
{
  "query": "хочу к морю и маякам",
  "start_date": "2026-10-22",
  "end_date": "2026-10-24",
  "transport": "car"
}
```

- Даты необязательны, но передаются вместе; диапазон 1–7 дней.
- `transport`: `car`, `foot`, `bike`, `transit`.
- Если даты не переданы, intent парсится из текста (по умолчанию 2 дня).
- `GET /api/health` отдаёт `auth_required`, чтобы UI не показывал токен зря.
- План отдаёт `days[].items[]`, `days[].legs[]`, `weather[]`, `warnings[]`, `sources[]`,
  `lodging[]` (выбранное) и `lodging_options[]` (все варианты для блока «Где остановиться»).

## Чек-лист ручной проверки

1. Открыть `/`, карта Приморья видна, zoom +/− работают, атрибуции Leaflet нет.
2. Ввести «Хочу к морю и маякам», не трогать даты — план на столько дней, сколько разобрано из текста; поля дат синхронизируются с intent.
3. Сменить транспорт на «Пешком» — в meta и в intent транспорт `foot`.
4. Сменить даты на 1 день — план на 1 день, даты совпадают.
5. Ввести «Реши задачу по алгебре» — отказ, плана нет.
6. Задать `APP_TOKEN` на сервере — поле токена появляется; без него — скрыто.
7. Проверить источник точки: в карточке должна быть ссылка «Источник: Wikipedia/OpenStreetMap», а не сырой `place_id`. Validation и trace остаются в API (`/api/runs/{id}`), но не показываются в UI.
